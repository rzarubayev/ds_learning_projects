# Мониторинг Веб-сервиса

Для мониторинга Веб-сервиса совместно с его Docker контейнером посредством 
Docker Compose развернуты контейнеры Prometheus для сбора метрик и Grafana 
для их отображения. 

## Метрики 

Мониторинг метрик осуществляется посредством дашборда Grafana. На дашборд 
выведены следующие метрики:

1. Общие сведения о работе Веб-сервиса:
    - время запуска;
    - используемые ресурсы;
2. HTTP запросы к Веб-сервису:
    - общее количество запросов;
    - среднее время обработки запросов;
    - количество и процент ошибок;
3. Метрики модели рекомендаций:
    - метрики предсказаний модели по активным и по всем пользователям.
    - количество успешно обработанных запросов по их видам в виде эндпоинтов 
    запросов.

Веб-сервис для публикования метрик использует модуль 
`prometheus_fastapi_instrumentator`.

Также для Веб-сервиса определены два вида кастомных метрик:
    - Gauge метрика `models_metric` с метками `model_name` и `metric`, которые 
    могут собирать статистику по любым используемым в Веб-сервисе моделям и 
    метрикам таких моделей. 
    - Counter метрика `model_success_requests` с метками `model_name` и 
    `endpoint`, которые предназначены для сбора статистики об успешных 
    выполнениях запроса на получение предсказаний или данных от любых моделей 
    Веб-сервиса.

## Prometheus 

Для сервиса Prometheus используется Docker образ `prom/prometheus`. Файл 
конфигурации расположен по пути `monitoring/prometheus/prometheus.yml`. 
В целях тестирования установлен малый интервал для сбора метрик, который в 
Production среде лучше увеличиь, так как использование Веб-сервиса не 
предполагает высокое количество ежедневных запросов - разовые запросы по 
клиентам в разрезе банковских продуктов, и более частые запросы по продуктам 
на клиента.

Для сбора метрик с Веб-сервиса рекомендаций в файле конфигурации добавлен job 
с под названием `scraping-ml-service` с указанием адреса, схемы подключения и 
пути для сбора метрик.

# Grafana

Для сервиса Grafana используется Docker образ `grafana/grafana`. Порт, логи и 
пароль к сервису представлены в .env файле. Добавлен источник Prometheus, 
который был настроен и протестировано подключение к сервису Prometheus.

Подготовлен Dashboard для отображения метрик, который частично использует 
визуализации одного из общедоступных на сайте grafana.com 
[шаблонов](https://grafana.com/grafana/dashboards/16110-fastapi-observability) 

Дополнительно были добавлены сведения об используемых ресурсах, которые 
доступны по эндпоинту `/metrics`, а также кастомные метрики Веб-сервиса.

Для возможности использования Grafana после перезапуска контейнера в файл 
Docker Compose добавлен локальный том `monitoring/grafana`, который 
монтируется к контейнеру по пути `/var/lib/grafana`.
